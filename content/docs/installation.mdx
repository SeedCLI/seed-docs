## Prerequisites

Seed CLI requires **Node.js 24** or later.

```bash
# Check your Node.js version
node --version
```

If you need to install or update Node.js, visit [nodejs.org](https://nodejs.org/) or use a version manager like [fnm](https://github.com/Schniz/fnm) or [nvm](https://github.com/nvm-sh/nvm).

## Scaffolding a New Project

The fastest way to start is with the `create-seedcli` scaffolding tool:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">
  ```bash
  npm create seedcli my-cli
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash
  pnpm create seedcli my-cli
  ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn create seedcli my-cli 
  ```
  </Tab>
  <Tab value="bun">
  ```bash
  bun create seedcli my-cli
  ```
  </Tab>
</Tabs>

This creates a new project with:

- Pre-configured `tsconfig.json`
- Example commands
- Build and compile scripts via `@seedcli/cli`
- Dev mode with file watching

## Manual Installation

Every Seed CLI project needs the core package:

{/* biome-ignore format: preserve multiline Tab children for MDX rendering */}
<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">

  </Tab>
  <Tab value="pnpm">
  ```bash
  pnpm add @seedcli/core
  ```
  </Tab>
  <Tab value="yarn">
  ```bash
  yarn add @seedcli/core
  ```
  </Tab>
  <Tab value="bun">
  ```bash
  bun add @seedcli/core
  ```
  </Tab>
</Tabs>

### Individual Modules

Install only the modules you need:

```bash
# Examples (use your package manager of choice)
npm install @seedcli/print @seedcli/prompt @seedcli/filesystem
```

<Callout type="info">
  When using modules inside a Seed command's `run` function, built-in context modules like `print`, `prompt`, and `filesystem` are available automatically via the seed context — no direct install needed.
</Callout>

### Umbrella Package

## Project Structure

The **Full** template scaffolds the following structure:

```
my-cli/
├── src/
│   ├── commands/
│   │   └── hello.ts        # Example command
│   ├── extensions/
│   │   └── timer.ts        # Example extension
│   └── index.ts            # Entry point
├── tests/
│   └── hello.test.ts       # Example test
├── .gitignore
├── biome.json
├── package.json
├── seed.config.ts           # CLI configuration
└── tsconfig.json
```

<Callout type="info">
  The **Minimal** template is slimmer — it omits `seed.config.ts` and `extensions/`, but still includes a basic test file. See [create-seedcli](/cli/create-seedcli) for a full template comparison.
</Callout>

## TypeScript Configuration

The scaffolded `tsconfig.json` (Full template) includes:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "esModuleInterop": true,
    "strict": true,
    "skipLibCheck": true,
    "declaration": true,
    "isolatedModules": true,
    "verbatimModuleSyntax": true,
    "noEmit": true,
    "types": ["node"]
  },
  "include": ["src/**/*.ts"],
  "exclude": ["node_modules", "dist"]
}
```

For packaging guidance, see [Build](/build) and [Distribution](/distribution). For the full `seed build` flag reference, see [seed build](/cli#seed-build).
